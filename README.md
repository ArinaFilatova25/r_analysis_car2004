# Car2004 | Statistical Data Analysis in R

### Статистический анализ автомобильных данных с использованием R

## О проекте

Проект посвящён исследованию набора данных **Car2004**, содержащего характеристики автомобилей, их технические параметры и цены.

**Цель проекта** — исследовать взаимосвязи между характеристиками автомобилей, изучить факторы, связанные с их стоимостью, выявить скрытую структуру данных и сравнить различные методы многомерного статистического анализа.

В рамках проекта выполнены разведочный анализ данных (EDA), проверка статистических гипотез, корреляционный и регрессионный анализ, методы снижения размерности, кластеризация и классификация.

Все исследования реализованы на языке **R** и представлены в формате **R Markdown**.

## Данные

**Датасет:** Car2004

Набор данных содержит информацию об автомобилях различных производителей и категорий.

Основные характеристики:

- `Retail` — розничная стоимость автомобиля.
- `Dealer` — дилерская стоимость.
- `Engine` — объём двигателя.
- `Cylinders` — количество цилиндров.
- `Horsepower` — мощность двигателя.
- `CityMPG` — расход топлива, выраженный в милях на галлон, в городском цикле.
- `HW_MPG` — экономичность автомобиля на шоссе.
- `Weight` — масса автомобиля.
- `Wheelbase` — колёсная база.
- `Length` — длина автомобиля.
- `DriveTrain` — тип привода.
- `Type` — тип кузова.

Исследование охватывает как количественные, так и категориальные переменные.

## Этапы исследования

### 1. Exploratory Data Analysis (EDA)

Проведён предварительный статистический анализ автомобильных данных.

**Основные задачи:**

- Исследование структуры датасета.
- Анализ распределений числовых признаков.
- Проверка симметричности распределений.
- Выявление выбросов и неоднородностей.
- Визуализация зависимостей между характеристиками автомобилей.
- Исследование корреляций и частных корреляций.

Дополнительно проведено сравнение распределений стоимости автомобилей между различными категориями.

Использованы статистические критерии:

- Mann–Whitney U Test.
- Kolmogorov–Smirnov Test.
- Тесты на нормальность распределений.

### 2. Regression Analysis

Проведён регрессионный анализ для исследования зависимостей между характеристиками автомобилей.

**Основные этапы:**

- Подготовка данных и обработка пропущенных значений.
- Исследование корреляций между признаками.
- Построение регрессионной модели.
- Анализ мультиколлинеарности с использованием VIF.
- Отбор признаков методами Forward и Backward Stepwise Selection.
- Диагностика модели и анализ остатков.
- Выявление влиятельных наблюдений.

Для диагностики использованы:

- Cook's Distance.
- Mahalanobis Distance.
- Studentized Residuals.
- Leverage.

### 3. Principal Component Analysis (PCA)

Метод главных компонент применён для исследования структуры многомерных данных и снижения размерности.

**Выполнено:**

- Анализ собственных значений и собственных векторов.
- Исследование факторных нагрузок.
- Вычисление главных компонент.
- Анализ доли объяснённой дисперсии.
- Визуализация структуры данных.

Основные визуализации:

- Scree Plot.
- Factor Map.
- Biplot.

### 4. Factor Analysis

Проведён факторный анализ для выявления скрытых факторов, объясняющих взаимосвязи между характеристиками автомобилей.

**Основные этапы:**

- Анализ корреляционной структуры признаков.
- Определение количества факторов.
- Использование параллельного анализа.
- Построение двухфакторной и трёхфакторной моделей.
- Интерпретация факторных нагрузок.

Исследованы методы вращения факторов:

- Varimax — ортогональное вращение.
- Oblimin — косоугольное вращение.

### 5. Clustering Analysis

Применены различные алгоритмы кластеризации для исследования групп автомобилей со схожими характеристиками.

**Рассмотренные методы:**

1. K-means.
2. K-means++.
3. Hierarchical Clustering.
4. Gaussian Mixture Models.
5. Spectral Clustering.

Дополнительно использован PCA для исследования структуры данных и визуализации результатов кластеризации.

### 6. Discriminant Analysis and Classification

Проведён дискриминантный анализ для классификации автомобилей по категориальным характеристикам.

**Задачи классификации:**

- Определение типа привода автомобиля.
- Классификация по типу кузова.
- Разделение спортивных автомобилей и внедорожников.

**Методы:**

- Linear Discriminant Analysis (LDA).
- Quadratic Discriminant Analysis (QDA).

Дополнительно проведены:

- Проверка предположений о нормальности.
- Box's M Test для проверки равенства ковариационных матриц.
- Проверка гипотез о равенстве средних в классах.
- Визуализация результатов классификации.

### 7. Canonical Correlation Analysis (CCA)

Канонический корреляционный анализ применён для исследования взаимосвязей между двумя группами количественных признаков.

**Основные этапы:**

- Формирование групп переменных.
- Вычисление канонических переменных.
- Исследование канонических корреляций.
- Визуализация первых канонических переменных.
- Анализ результатов с учётом типа привода автомобилей.
